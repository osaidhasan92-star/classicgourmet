# Classic Gourmet Fine Foods — Static Website

Clean static HTML/CSS/JS recreation inspired by the supplied Prime Gourmet reference website.

## Changes
- Rebranded to Classic Gourmet Fine Foods using the supplied logo.
- Color system follows the logo: navy, green, red, orange and warm cream.
- Removed shopping cart / checkout functionality.
- Removed FAQs.
- Removed Blog.
- Removed Our Stores / locations section.
- No Shopify, WordPress, PageFly, HTTrack or other unnecessary source folders.
- Responsive mobile navigation.
- Responsive hero slider.
- Separate HTML pages for product categories, About, Special Offers and Contact.
- Uses local image assets from the supplied website archive.
- Images are not repeated between the major home-page sections.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any simple static web server.

Example:
`python -m http.server 8000`

Then open:
`http://localhost:8000`
